# Productivity

General workflow tools, not code-specific.

- **[eng-grill-me](./eng-grill-me/SKILL.md)** — Get relentlessly interviewed about a plan or design until every branch of the decision tree is resolved.
- **[eng-handoff](./eng-handoff/SKILL.md)** — Compact the current conversation into a handoff document so another agent can continue the work.
- **[eng-write-a-skill](./eng-write-a-skill/SKILL.md)** — Create new skills with proper structure, progressive disclosure, and bundled resources.
